## 4. ⚠ 게인비를 스텝에서 뽑는 방법은 ±1.5% 다

08-27 sensing §3 은 두 컨트롤러의 대기전류가 같다고 보고 스텝의 비를 게인비의 역수로 썼다.

```
08-27   9.4438 / 9.4265 = 1.0018      ← 08-21 스왑 시험 1.0022 와 0.04%
08-28   7.231  / 7.114  = 1.0165      ← 1.4% 어긋난다
```

두 채널의 **절대** 차가 0.017 → 0.117 LSB 로 바뀌었을 뿐이다. 둘 다 1 LSB 이하인데, 분모가
7~9 LSB 뿐이라 비가 그것을 증폭한다. 캡처 안의 표준오차로 계산한 비의 정밀도는 ±0.4% 인데
실제 하루 간 산포는 **±1.5%** 다 — 한계는 측정 잡음이 아니라 *"두 컨트롤러의 대기전류가
같다"* 는 전제와 스텝 자체의 불안정이다.

**08-14 의 1.0322 를 반증하는 방향은 유지된다** (두 값 모두 그보다 아래다). 그러나 08-27 이
쓴 *"세 번째 독립 증거 · 0.04% 일치"* 는 **우연이었고 정밀도로 인용해서는 안 된다.**
08-21 스왑 시험(각 센서로 두 모터를 모두 재서 DMM 을 상쇄)은 설계상 이 방법보다 강하며,
게인비의 최선값은 여전히 **1.0022** 다. 조치 #36.

## 5. ⚠ 캡처 간격이 오늘은 7.2 분이었다 — 그래도 설명이 안 된다

계획은 3 분을 요구했다. 실제 간격(OFF 종료 → ON 시작)은 **434 s = 7.2 분**이다 (08-27 은
96 s = 1.6 분). 간격이 길면 그 사이의 드리프트가 스텝에 그대로 실린다.

각 캡처(60 s · 3000 표본) 안에서 직접 기울기를 재서 크기를 잡았다:

| | gp27 | gp28 |
|---|---:|---:|
| 08-28 OFF 캡처 내 기울기 | +0.092 LSB/분 | +0.016 |
| 08-28 ON 캡처 내 기울기 | **−0.278** | −0.068 |
| 두 기울기 평균 × 7.2 분 | **−0.76 LSB** | −0.22 LSB |

기울기가 음이므로 ON 이 오히려 **눌린** 방향이다. 보정하면 스텝은 7.99 / 7.33 로 **커진다**
— 08-27 의 9.43 과는 여전히 1.4~2.1 LSB 벌어져 있다.

> **간격은 최대 0.8 LSB 를 설명하고, 관측된 차이는 2.2 LSB 다.**

⚠ 60 s 기울기를 7 분으로 외삽한 것이므로 상한 추정이지 보정값이 아니다. #27 의 흔들림은

### 이 문서가 §7 교정에 넘기는 것

1. **§7.3 의 DMM 직렬 정지 1 점이 유일한 절대 경로다.** §3 이 상대 방법(스텝 비교)을

   Pico 스텝(LSB)과 DMM 정지 전류(A)가 짝지어져 **저전류 구간의 절대 게인 점**이 하나 더
   생긴다. 오늘 §3 이 만든 공백을 정확히 메운다
3. **그때 컨트롤러는 4 시간 넘게 통전·고온이다.** §4.2 의 통전 시간 가설이 맞다면 스텝은

4. **영점 쌍은 3 분 안에** (§5)
