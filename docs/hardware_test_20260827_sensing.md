## 1. ★ 참 0 A 기준 — 최초

배터리 메인은 **두 스위치로 분기**된다. 모터 버스와 라즈베리파이가 따로다. **모터 스위치만
끄면 센서를 통과하는 도선에 전류 경로 자체가 없어지는데**, 파이와 Pico 는 살아 있으므로
그 상태를 그대로 캡처할 수 있다.

지금까지의 모든 영점 — 펌웨어 `Z`, 모든 세션의 모든 정지 구간 — 은 **컨트롤러가 켜진 채**라
대기전류가 섞여 있었다.

| | `zero_off_cold_0827` (OFF = 참 0 A) | `zero_on_cold_0827` (ON · 정지) | **스텝** |
|---|---:|---:|---:|
| **gp27** (id=2) | **2033.486** ± 0.015 | 2042.930 ± 0.016 | **+9.4438** |
| **gp28** (id=1) | **2031.270** ± 0.015 | 2040.697 ± 0.016 | **+9.4265** |
| gp28 − gp27 | −2.216 | −2.233 | −0.017 |
| n / σ | 3011 / 0.81 | 3032 / 0.87 | |

- 03:38:14–03:39:14 (OFF) → 03:40:50–03:41:50 (ON). **간격 95.7 s, 전체 3.6분.**
- 표준오차 0.015 LSB ≈ **0.18 mA** — 계획이 요구한 0.3 mA 보다 좋다.
- ⚠ OFF 상태에서 **GP26 은 죽는다** (raw 267.7, σ 19.5, p-p 644 mV). 분압기가 스위치
  하류라 부유 노드가 된다. MD400 도 양쪽 id 무응답. **정상이며 고장이 아니다.**
- ⚠ **`Z` 를 보내지 않았다.** `volt_compare.py` 는 `C`/`S`/`X` 만 보낸다.

### 1.1 어제 남긴 "귀속 불가"를 닫았다

08-26 마지막 커밋은 같은 관측을 하고도 **두 측정 사이에 1시간이 있어 조치 #27 드리프트가
섞였다**며 귀속을 포기했다. 오늘은 3.6분이다.

| | 08-26 저녁 (간격 1시간) | **오늘 (간격 3.6분)** |
|---|---:|---:|
| gp27 스텝 | +8.5 | **+9.4438** |
| gp28 스텝 | +8.9 | **+9.4265** |

어제 값이 오히려 **작다.** 그 1시간의 드리프트는 스텝을 부풀린 게 아니라 깎고 있었다.

## 2. ⚠ 대기전류가 문서값보다 47% 크다 (신규 — 조치 #45)

08-14 교정 게인으로 환산한다.

```
gp28   9.4265 LSB × 12.0289 mA/LSB = 113.4 mA
gp27   9.4438 LSB × 11.6534 mA/LSB = 110.1 mA

문서   DMM 실측 0.077 A (양 유닛 모두 0.077~0.078)
펌웨어 QUIET_GP28 = 6.396 LSB / QUIET_GP27 = −6.452 LSB   (≡ 77 mA)
```

**드리프트로는 설명되지 않는다** — 오늘 두 캡처는 3.6분 간격이다. 후보는 셋이다.

| # | 가설 | 판정 방법 |
|---|---|---|
| 1 | **08-14 의 절대 게인이 낮다** — 참값이 77 mA 라면 필요한 게인은 **8.16 mA/LSB**, 08-14 대비 −32% | **§3.4 교정** |
| 2 | **대기전류가 실제로 늘었다** — 08-14 이후 배선이 바뀌었다(#36). 계측 급전선에 부하가 더 붙었다면 그대로 나타난다 | **DMM 직렬 상태에서 정지 1점** |
| 3 | 스텝의 일부가 전류가 아니다 (버스 통전 시 공통모드 이동) | §3 의 게인비 일치가 이 쪽을 약화시킨다 |

> **내일 §3.4 에서 DMM 을 직렬로 꽂은 직후, 모터를 돌리기 전에 정지 1점을 반드시 읽을 것.**
> 가설 2 가 거의 공짜로 닫힌다.

## 3. ★ 게인비 1.0018 — 08-14 채널 게인의 세 번째 반증

두 컨트롤러는 같은 기종이므로 대기전류가 같다고 보면, **스텝의 비가 곧 게인비의 역수**다.

```
오늘         9.4438 / 9.4265 = 1.0018
08-21 스왑   참 게인비       = 1.0022      ← 0.04% 일치
08-14 교정                  = 1.0322      ← 3.2%
```

08-21 §5 의 스왑 시험은 **각 센서로 두 모터를 모두 재서 DMM 을 상쇄**하는 설계였고, 오늘은
**대기전류를 공통 입력으로 쓴** 완전히 다른 경로다. 두 독립 방법이 1.002 에서 만난다.

08-14 가 3.2% 를 준 이유는 그 보고서가 스스로 경고한 대로다 — 무부하 전류가 ±20 A 센서의
맨 아래 구간이라 **raw 스팬이 14 LSB** 뿐이었다.

⚠ 이것은 **비**만 말한다. 절대값(§2)은 §3.4 몫이다. 그리고 08-21 의 `+3.0% 정정`을 그대로
적용해서는 안 된다 — 그건 스왑 당시 배선의 값이다 (조치 #36).

## 4. 조치 #27 재해석 — 드리프트가 아니라 계단이다

### 4.1 하루 단위로는 안 움직인다

| 비교 | 간격 | 이동 |
|---|---|---|
| 참 0 A: 08-26 저녁 → 오늘 | 19.5 h | gp27 **−0.49**, gp28 **+0.63** LSB |
| 통전 정지: 08-26 → 오늘 | 19.5 h | gp27 +0.1~0.6, gp28 +1.0~1.4 LSB |
| 세션 안 (08-26) | 20 분 | **−2.46 LSB** |
| 세션 안 (오늘, preflight→ON 캡처) | 2 h | **+2.6 LSB** |

**20분에 −2.46 이 흐른 채널이 19.5시간 뒤에 +1.37 로 돌아와 있다.** 단조 드리프트는 이럴 수
없다. **±2.5 LSB 범위의 유계 흔들림**이다.

그런데 `preflight.py` 의 세션 기준선(8/11·8/12)과는:

```
gp27  2040.26  vs  2052.9~2053.4   →  12.6 LSB
gp28  2038.10  vs  2068.0~2070.1   →  29.9 LSB     ← 2.4 배 차이
```

두 채널의 간극 크기가 2.4배 다르므로 **공통 드리프트가 아니다.** 흔들림이 쌓인 것도 아니다.
**배선 변경 시점의 계단**으로 보는 것이 맞다.

### 4.2 ⚠ 08-18 의 수치 분해는 성립하지 않는다

08-18 §5 는 8/15→8/18 변화를 "레일 +0.99% + 채널당 −102 mA"로 분해했다. 그 분해는
**"부호가 반대라 `x` 가 반대로 들어간다"** 를 전제로 한다:

```
2066.55·(ρ−1) + x = −28.80   (gp28)
2052.30·(ρ−1) − x = −11.71   (gp27)     ← x 부호 반대
```

**조치 #35 가 08-26 에 그 전제를 뒤집었다** — GP27 은 raw 상에서 역방향이 아니고, 거꾸로인
것은 펌웨어의 `sign_gp27 = -1` 상수다. 오늘 §1 의 스텝도 두 채널이 **같은 방향으로 같은 폭**
(+9.4438 / +9.4265)이라 이를 독립 확인했다. 같은 부호로 다시 풀면:

```
14.25·(ρ−1) = −17.09   →   ρ = −0.199      ← 물리적으로 불가능
```

즉 그 변화는 **"공통 레일 + 공통 전류"로 분해되지 않는다.** 17 LSB 의 차동 성분에는 진짜
차동 원인(한쪽 센서의 배선·오프셋, 채널별 급전)이 필요하다. **08-18 의 "레일 +0.99% /
−102 mA" 는 폐기하고, 08-18 이 세운 "대기전류가 더 이상 센서를 통과하지 않는다"는 가설도
§1 이 반증한다** — 지금 리그에서 대기전류는 두 센서를 분명히 통과한다.

### 4.3 실무상

**결과에는 영향이 없다.** 모든 시험이 로컬 영점을 쓰고, 채널 차가 −2.2 LSB 대에서 안정하므로
좌우비·방향비에서 상쇄된다. 영향받는 것은 저장 절편 기준의 절대 전류 표시뿐이며, 그게 #4 다.

## 5. 분압비 — DMM 28.59 V 로 독립 확인

운전자가 세션 중반 DMM 으로 배터리 28.59 V 를 읽었고, `warm1` 실행 중이라 그 런의 정지
구간 GP26 과 짝지을 수 있다 (`--dmm 28.59` 로 로그에 기록됨).

`warm1` 의 정지 구간은 28.5983 → 28.5858 V 로 3.5분간 12.5 mV 내려간다. DMM 을 읽은 정확한
시각을 모르므로 그 창 전체로 `D` 를 풀면:

```
D = V_DMM / ((raw + 19.60) × LSB_V),   LSB_V = 3.280/4095 = 8.009768e-4

창 시작 (raw 3187.92)  →  D = 11.1281
창 끝   (raw 3186.53)  →  D = 11.1329
                            ────────────
확정값                        D = 11.131      ← 창 안에 있다
```

**08-26 교정점은 24.58 / 24.83 V 였다. 이 점은 4 V 위다.** 절편을 고정한 뒤 서로 멀리 떨어진
점들이 `D` 에서 일치한다는 것은 **"기울기 = 분압비 / 절편 = 접지 오프셋" 분해가 옳다**는
증거다 — 좁은 구간에서 둘이 서로를 흉내내던 08-13~08-19 의 축퇴가 진짜로 풀렸다.

⚠ 벨트 텐션 변경은 **기계적 변경**이라 Δ 를 건드리지 않는다. 조치 #40 은 발동하지 않는다.

### 5.1 배터리 궤적 (참고)

| 시점 | GP26 raw | V_bus |
|---|---:|---:|
| `cold1` 시작 | 3192.72 | 28.6410 |
| `coldp` 종료 | 3188.30 | 28.6016 |
| `warm1` 시작 | 3187.92 | 28.5983 |
| `warmp` 종료 | 3184.43 | 28.5671 |

세션 전체 **−74 mV ≈ 0.10 Ah** (평탄 구간 0.72 V/Ah 기준). 계획 추정 0.15 Ah 보다 적다.

## 6. 조치 #46 (신규) — `Z` 경로와 스트림 경로가 3 LSB 다르다

`preflight.py` 실행 중, **같은 분 · 같은 버스 상태**에서 두 값이 어긋났다.

```
#ZERO (Z, 1024 표본, 타이트 루프)   gp28 2034.938   gp27 2037.270
20 s 스트림 평균 (라운드로빈)        gp28 2038.10    gp27 2040.26
                                     ────────────    ───────────
차                                     +3.16           +2.99   LSB  (≈ 36 mA)
```

표준오차(0.03 LSB) 대비 100배다. 두 경로는 실제로 다르다:

- `calibrate_zero()` — gp27/gp28 만 번갈아, 페이싱 없는 타이트 루프. **GP26 을 안 읽는다.**
- `sample_window()` — GP26 포함 3채널 라운드로빈, `N_DISCARD=1`, 창의 80%에 분산.

⚠ 다만 08-11 §3 은 **GP27/GP28 은 ACS758 이 저임피던스로 구동하므로 정착 오차가 없다**고
못박았다. 그 메커니즘으로는 설명되지 않는다. 08-11 이 기록한 예열 이동(부팅 직후 대 예열 후
5 raw ≈ 49 mA)과 크기·방향이 맞는 쪽이 더 유력하다.

**실무 함의**: `Z` 의 저장 영점을 기준으로 쓰지 않는 이 저장소의 방침이 옳다는 것이 수치로
확인됐다. 그리고 **§3.3 의 스위치 OFF 캡처는 교정과 같은 정도로 예열된 뒤에 잡아야 한다.**

## 7. 코드 — `volt_compare.py` 전압 축 통일

`preflight.py` · `breakin.py` 는 08-26 확정 상수로 갔는데 `volt_compare.py` 만 펌웨어의
`#CFG div` 를 쓰고 있었다. 같은 raw 에 **29.183 V 대 28.670 V** 로 0.5 V 어긋났다.

| 변경 | 내용 |
|---|---|
| `GP26_B_LSB` / `GP26_V_PER_LSB` + `bus_volts()` | `breakin.py` 와 같은 자. 세 도구가 소수점 6자리까지 일치 |
| `fw_v_per_lsb` 로 개명 | 펌웨어 환산은 **대조용**으로 남기고 한 줄 더 찍는다 (조치 #41 미반영 표시) |
| `필요한 scale_v` 제안 삭제 | 분압비는 닫혔다. MD400 앵커 역산은 11.1039 (0.24% 밖)를 내고 있었다 |
| 전류 채널 raw 평균·σ·표준오차 출력 | 영점 캡처에서는 이게 결과 그 자체다 |

교차 확인: 08-21 노트북 점(raw 2893.888, DMM 25.99 V) → **25.977 V (−13 mV)**, 20260826
sensing §1.5 의 값과 같다.
