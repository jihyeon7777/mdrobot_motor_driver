## 4. `coldpb` 통신 중단 — 쓰기 경로에 재시도가 없었다

C1 을 양쪽 100% 추종으로 완주한 뒤 C2 진입에서 끊겼다.

```
!! 예외: IncompleteResponseError: short read: got 0 want 2:
[정지 시퀀스]
    완료 — 모터 출력 차단됨
```

**모터는 안전하게 정지했다** — `finally` 의 stop → torque_off → disable 이 돌았고 C1 은
기록됐다.

### 4.1 원인 지점

`breakin.py` 의 폴링 루프는 **이미 3 회 연속 실패까지 관용한다** (`:236-239`). 그런데 이
예외는 거기가 아니라 **구간 전환의 명령 쓰기**(`set_cmd` → `set_velocity`, `enable`)에서 났고,
그 경로에는 재시도가 없어 **1 회 실패가 곧 런 중단**이었다. 같은 파일 안에서 읽기는 관용하고
쓰기는 안 하는 비대칭이었다.

08-14 의 선례(`short read: got 0`, 40/40)는 **id=2 전원이 내려가 있던 지속 고장**이라 성격이
다르다. 오늘 것은 단발이고, 정지 시퀀스(버스 쓰기 필요)가 직후에 성공했다.

### 4.2 조치 — 쓰기 재시도 (이 세션에서 수정)

`WRITE_RETRY = 3` · `WRITE_RETRY_DT = 0.05 s` 를 `set_cmd` 와 `enable` 에 걸었다.

- **폴링 루프의 3 회 관용과 같은 정책**이다. 새 방침이 아니라 비대칭을 없앤 것
- `ModbusClient._transact` 가 매 트랜잭션 앞에서 `flush_input` 을 부르므로 재시도에 묵은
  바이트가 안 섞인다. `set_velocity`·`enable` 은 같은 값을 다시 쓰는 **멱등** 연산이다
- **지속 고장은 그대로 중단시킨다** — 08-14 같은 전원 문제를 가리지 않는다
- 최악 추가 지연 0.10 s/쓰기 (램프 간격 0.30 s 안)
- 재시도가 일어나면 요약 말미에 `※ id=N: 명령 쓰기 재시도 N 회` 로 **보고된다**
- ⚠ **`bi1b` 부터 적용된다.** `cold*b` 세 런은 수정 전 스크립트로 돌았다

⚠ `short read: got 0 want 2` 는 2 바이트 헤더 읽기 타임아웃이다 — **응답 유실이지 프레임
깨짐이 아니다.** 재시도가 맞는 처방인 근거다.

## 5. 제조사 표 2 회차 — 계단은 런 간격에 오염된다

08-26 인자 그대로 `bi1b`~`bi4b`. 전 런 추종 100.0%, 저전압 중단 없음, **쓰기 재시도 0 회.**

### 5.1 방법 검증

토막별 전력을 `cycle_report` 와 같은 규약으로 다시 계산해 **08-26 발표값을 정확히 재현**했다
(`bi3` CW 45.15 → 42.42 → 41.64, `bi4` CW 62.40 → 58.12 → 57.11 → 56.74). 아래 수치는 모두
그 방법으로 낸 것이다.

### 5.2 ⚠ 계획서의 대조 기준을 정정한다

계획서는 *"각 단계 첫 5 분 토막의 계단, 08-26 은 −6~7%"* 를 수렴 지표로 제시했다. 그 −6~7% 는
**`bi3`·`bi4` 값이다.** `bi1`·`bi2` 는 토막이 2 개뿐이라 08-26 도 예열과 길들임을 못 갈랐다
(08-26 §5: *"그때는 토막이 2 개뿐이라 못 갈랐다"*). 오늘 `bi1b`·`bi2b` 도 같은 2 토막이므로
**수렴 판정은 `bi3b`(3 토막)·`bi4b`(4 토막)에만 걸 수 있다.**

### 5.3 ★ 첫 계단은 수렴 지표가 아니다 — 런 간격에 지배된다

각 단계의 **CW 첫 계단은 런 진입 전에 얼마나 식었나**에 지배된다. 오늘 런들은 앞 런 종료
**15 초** 뒤에 들어갔고, **08-26 의 런 간격은 기록이 없다** (로그에 절대시각이 없고, 사이클
CSV 는 07:29 에 일괄 재작성돼 mtime 도 못 쓴다).

| CW 첫 계단 | 08-26 | 오늘 |
|---|---:|---:|
| `bi1` / `bi1b` 500 | −3.19% | −2.71% |
| `bi2` / `bi2b` 1000 | −6.23% | −3.53% |
| `bi3` / `bi3b` 2000 | −6.05% | −4.59% |

전부 작아졌지만 **귀속 불가**다. 08-26 전압표가 방증을 준다 — 런 사이 무부하 전압 변화가
`bi1→bi2` **−0.068 V**, `bi2→bi3` −0.028 V, `bi3→bi4` **+0.018 V**(부하 해제 후 회복)다.
무부하에서 0.068 V 가 빠지려면 시간이 흘러야 하므로 **`bi2` 앞 간격이 가장 길었을 공산이
크고**, 그것이 `bi2` 의 −6.23% 를 부풀렸다고 보면 앞뒤가 맞는다.

> **첫 계단은 세션 간 비교에 쓰지 않는다. 2nd 이후 계단만 간격에 면역이다.**

### 5.4 간격 면역 계단 — 수렴은 있으나 완만하다

같은 런 안에서 이미 데워진 뒤의 계단이라 진입 열 상태와 무관하다.

| 2nd 계단 | 08-26 | 오늘 | 차 |
|---|---:|---:|---:|
| `bi2` CCW 1000 | −2.54% | −2.33% | +0.21 %p |
| `bi3` CW 2000 | −1.84% | −1.62% | +0.22 %p |
| `bi3` CCW 2000 | −1.97% | −1.61% | +0.36 %p |

**세 쌍 모두 같은 방향으로 줄었다.** 다만 크기가 0.2~0.4 %p 로 작다. 08-26 이 `bi4` 에서
*"수렴이 시작됐다"* 고 읽은 −1.74% → −0.65% 감쇠에 비하면 훨씬 완만하다.

### 5.5 ★ 방향비가 세 속도에서 모두 1 쪽으로 갔다

| | 속도 | 방향비1 (id1) | 방향비2 (id2) | 좌우비 |
|---|---:|---|---|---|
| `bi1` → `bi1b` | 500 | **1.2249 → 1.0141** | 0.8464 → **0.8967** | 1.1355 → 1.1848 |
| `bi2` → `bi2b` | 1000 | **1.1289 → 0.9755** | 0.8521 → **0.8712** | 1.1356 → 1.2039 |
| `bi3` → `bi3b` | 2000 | **1.1183 → 0.9313** | 0.8757 → **0.8803** | 1.1372 → 1.1547 |

두 채널의 움직임이 **성격이 다르다**:

- **id1 은 세 속도에서 거의 같은 크기로 내려갔다** (−0.21 / −0.15 / −0.19). 1000·2000 에서는
  1 을 넘어 **반전**했다 — CW 가 무거운 쪽이 됐다. ⚠ **벨트 텐션 교락(#44)** 이 있는 채널이다
- **id2 는 저속일수록 크게 올라갔다** (+0.050 / +0.019 / **+0.005**). 2000 rpm 에서는 사실상
  변화가 없다

**id2 가 깨끗한 채널이고**, 08-26 이 *"브레이크인 90 분에 저속 −7~12%, 고속(1500)은 불변"*
이라 한 것과 모양이 같다 — 방향 비대칭 개선이 저속 현상이라는 관찰이 재현된다.

⚠ **다만 이 표만으로 브레이크인 몫을 읽으면 안 된다.** §6 이 밝혔듯 **방향비는 열에 강하게
의존한다** — id1 이 한 세션 안에서 냉간 1.082 → 온간 0.974 로 **−10%** 움직인다. 위 표의
`bi1`→`bi1b` −17% 중 얼마가 열이고 얼마가 브레이크인인지는, 두 런의 열 상태가 같았는지를
확인할 수 없으므로(§5.3 의 런 간격 미기록) **갈리지 않는다.**

> **브레이크인 몫은 §6.2 처럼 세션 안의 냉간→온간 대조로만 읽는다.** 그것이 세션 오프셋과
> 열 상태를 동시에 통제하는 유일한 형태다.

⚠ 반면 **좌우비는 세 속도에서 다 올랐고 속도 의존이 불규칙하다** (+4.3 / +6.0 / +1.5%).
08-26 은 좌우비가 속도와 무관하게 1.1355 / 1.1356 / 1.1372 로 붙박이였는데 오늘은
1.1848 / 1.2039 / 1.1547 로 흩어진다. **id1 텐션 교락의 직접적 결과로 읽는 것이 자연스럽고,
좌우비는 §7 게인 보정 전까지 판정에 쓰지 않는다** (#37·#44).

### 5.6 ⚠ 절대 전력은 세션 간 비교 불가 — 버스전압이 4 V 다르다

08-26 표는 **24.4 → 22.7 V**, 오늘은 **28.5 → 27.8 V** 에서 돌았다. 같은 기계 부하라도
저전압에서는 전류가 반비례로 커지고 동손은 그 제곱으로 붙는다. **계단(%)은 한 런 안 거의
일정한 전압에서 나오므로 이 영향을 안 받지만, 절대 W 는 받는다.**

⚠ 그리고 `bi*` 사이클 CSV 는 08-26 것이 일괄 재작성돼 있어 `--reanalyze` 산출일 수 있다
(§3.1 의 `cold1` 과 같은 사정). 위 방향비·좌우비는 0.2% 수준의 영향을 받을 수 있으나
보고한 차이(−0.15~−0.21)보다 두 자릿수 작다.

## 6. ★★ 사후 기준선 — 전진/후진 격차가 무너졌다

`bi4b` 종료 **1 분 뒤** 시작. 인자는 `cold*b` 와 완전히 같다.

### 6.1 ⚠ 먼저 — `warm*` 는 `post*` 와 같은 열 상태가 아니다

계획서의 2×2 격자는 08-27 `warmp` 를 `postp`·`postpb` 와 같은 "온간" 칸에 넣으라고 지시한다.
**절대 전력으로 보면 성립하지 않는다.**

| 대조 | 열 이력 | 버스 V | id1 P | 냉간 대비 |
|---|---|---|---:|---:|
| 08-26 `base1`→`post1` | 90 분 브레이크인 직후 | 24.56 → 22.06 | 12.129 → 8.756 | **−27.8%** |
| 08-27 `cold1`→`warm1` | **브레이크인 0 분**, 16 분 휴식 | 28.64 → 28.60 | 12.237 → 12.437 | **+1.6%** |

**`warm*` 는 사실상 냉간이다.** 저속 기준선 뒤 16 분 쉰 것이라 3000 rpm 으로 끝나는 표 직후와
같은 칸에 놓을 수 없다.

> **열 상태는 태그 이름이 아니라 절대 전력 낙폭으로 판정한다.**

### 6.2 ★ 깨끗한 채널(id2)의 브레이크인 신호

id2 는 텐션 변경(#44)을 안 거친 채널이다. **전부 세션 안의 냉간→온간 대조라 세션 오프셋에
면역이다** — §3.4 가 금지한 세션 간 셀 비교가 아니다.

| 세션 | 브레이크인 누계 | 냉간 asym2 | 온간 asym2 | **변화** | 절대 P2 낙폭 |
|---|---|---:|---:|---:|---:|
| 08-26 | 90 분 | 0.852 | 0.888 | **+4.2%** | −26.2% |
| 08-27 | **0 분** | 0.848 | 0.830 | −2.1% | +0.8% |
| **08-28** | **200 분** | 0.834 | **0.935** | **+12.2%** | −27.8% |

**열 부하가 같은데(−26.2% 대 −27.8%) 개선 폭이 3 배다.** 게다가 08-26 은 버스가 −10.6% 처져
동손이 낙폭을 **과소** 보이게 하므로 실제로는 08-26 쪽이 더 뜨거웠을 수 있다 — 오늘에 유리한
편향이 아니다. 브레이크인 0 분 세션(08-27)이 −2.1% 로 대조군 노릇을 한다.

⚠ 냉간 asym2 자체는 0.852 → 0.848 → 0.834 로 내려가는데 온간은 0.888 → 0.935 로 올라간다.
**냉간·온간 격차가 브레이크인과 함께 벌어진다.**

### 6.4 인공물이 아니다 — 세 런이 같은 말을 한다

| | 냉간 | 온간 | 변화 |
|---|---:|---:|---:|
| `post1b` 단독 asym1 | 1.0820 | 0.9742 | −10.0% |
| `post2b` 단독 asym2 | 0.8336 | 0.9351 | +12.2% |
| `postpb` 짝 asym1 | 1.1105 | 0.9872 | −11.1% |
| `postpb` 짝 asym2 | 0.8018 | 0.9184 | +14.5% |

**두 모터의 비대칭이 위아래에서 동시에 1 로 수렴한다.** 짝 구동에서는 두 모터의 무거운 방향이
반대라 서로 상쇄되므로, 개별 비대칭이 사라지면 전/후 격차도 사라진다 — 08-26 §7 의 모형 그대로다.

값들보다 오히려 단단하다.**

### 6.5 ⚠ 무엇이 아직 안 갈렸나

*"브레이크인이 해냈다"* 로 읽으면 안 된다. 교락이 넷이다.

1. **누적 200 분 대 90 분** — 관심 축이지만 다른 셋과 섞여 있다
2. **`bi4b` 는 3000 rpm CCW 를 완주했고 08-26 `bi4` 는 CW 절반에서 저전압 중단됐다** — 오늘
   리그가 표 끝에서 훨씬 균형 있게·뜨겁게 돌았다
3. **id1 텐션 변경** (#44)
4. **버스전압 27.3 V 대 21.7 V**

> **가르는 방법은 하나다 — 다음 세션의 냉간 값.** 밤새 식힌 뒤 `coldpb` 를 다시 잡아
> **1.03 근처면 구조적 변화**(브레이크인이 실제로 대칭화), **1.17 로 돌아가면 열 효과**다.

### 6.6 운용 함의 — 조치 #34 를 보류한다

08-26 §7 은 *"`id1(−) ↔ id2(+)` 를 전진으로 잡으면 17% 싸다"* 며 `twin_controllers.yaml` 의
`reverse_L`/`reverse_R` 을 뒤집을 것을 권했다. **그 17% 는 냉간 리그의 값이다.** 실제 로봇은
데워진 상태로 달리고, 오늘 온간 값은 **3.4%** 다.

⚠ **§6.5 가 닫히기 전에는 결선 뒤집기를 확정하지 말 것.** 다음 세션 냉간 값이 1.17 로
돌아오면 냉간 시동 구간에서는 여전히 의미가 있고, 1.03 이면 이 권고 자체가 근거를 잃는다.
