## 1. 조건

- 감속기는 08-21 교체분 그대로. 이번에도 교체·교차 없음.
- ⚠ **id1 벨트 텐션이 08-26 세션 이후 약간 바뀌었다.** 운전자 보고이며, **오늘 `cold*` 실행

- 배터리 만충에서 시작. 세션 전 구간 28.64 → 28.57 V (총 −74 mV ≈ **0.10 Ah**).
- 세션 시간 03:30 ~ 04:46 (로컬).

### ⚠ 텐션 변경이 무엇을 무효화하는가

`base*`(08-26, 옛 텐션) → `cold*`(오늘, 새 텐션) 차이에는 **브레이크인 90분과 텐션 변경이
함께** 들어 있다. 분리 불가다.

| 지표 | 08-26 대비 해석 |
|---|---|
| **id1 단독** (총P, 방향비) | ⚠ **귀속 불가** |
| **좌우비 · 전/후** | ⚠ **id1 이 들어가므로 귀속 불가** (단, 열 성분은 §3 에서 분리됨) |
| **id2 단독** | ✅ **유효** — id1 을 안 거친다 |

**이 문서에서 브레이크인 몫으로 단정한 것은 없다.** §3 이 분리해 내는 것은 *열* 성분이며,

## 3. ★ 전진/후진 — 2×2 로 열과 리그가 갈렸다

`warm*` 재실행으로 **열 상태 × 리그 상태**의 2×2 가 완성됐다. 짝 런의 사이클 평균이다.

| 전/후 비 | **냉간** | **온간·고온** | 행 내 차 (열) |
|---|---:|---:|---:|
| **옛 텐션** (08-26) | `basep` **1.2024** | `postp` **1.1718** | **−2.55%** |
| **새 텐션** (오늘) | `coldp` **1.1935** | `warmp` **1.1623** | **−2.61%** |
| **열 내 차 (리그)** | **−0.74%** | **−0.81%** | |

- 두 행이 열 효과에서 **−2.55% / −2.61%** 로 일치한다.
- 두 열이 리그 효과에서 **−0.74% / −0.81%** 로 일치한다.
- **교호작용 없이 가산적**이다. 이 정도로 깨끗하게 갈리는 경우는 드물다.

### 3.1 08-26 §6.2 의 귀속은 틀렸다

08-26 §6.2 의 헤드라인은 **base 1.202 → post 1.171, −2.6%** 였고 이를 브레이크인 몫으로 읽었다.

오늘 `coldp` → `warmp` 는 **그 사이에 브레이크인이 전혀 없다.** 16분 휴식 후 같은 인자로
다시 돌렸을 뿐인데 **−2.61%** 가 나왔다. 08-26 의 −2.6% 와 크기가 같다.

> **전진/후진 비는 브레이크인이 아니라 열 상태를 따라간다.**
> 냉간 계열 1.2024 · 1.1935 / 온간 계열 1.1718 · 1.1623 — 열 상태로 두 무리가 갈린다.

`basep` 사이클 평균 1.2024 와 `postp` 1.1718 은 08-26 §6.2 의 표(1.202 / 1.171)와 일치한다 —
같은 지표를 보고 있다는 확인이다.

### 3.2 진짜 브레이크인 몫은 −0.8%

열을 고정하고 리그만 비교하면 **−0.74%(냉간) / −0.81%(온간)** 이다. 여기에도 텐션 변경이
섞여 있으므로 브레이크인 단독 몫은 그보다 작다.

**전진은 여전히 후진보다 약 19% 비싸다** (냉간 1.1935). 08-26 §3.2 가 세운 설명 — 두 모터의
무거운 방향이 서로 반대라 개별 개선이 짝에서 상쇄된다 — 이 결론을 더 강하게 지지한다.

## 4. 좌우비 — 벌어졌고, 열이 아니다

```
옛 텐션   1.1636 (냉간)  →  1.2026 (고온)
새 텐션   1.2235 (냉간)  →  1.2341 (온간)

냉간끼리  1.1636 → 1.2235   +5.15%
온간끼리  1.2026 → 1.2341   +2.62%
```

**두 열 상태 모두에서 벌어졌다** — 열로 설명되지 않는다. 다만 텐션 변경과 브레이크인이
섞여 있어 어느 쪽 몫인지는 오늘 데이터로 못 가른다.

⚠ 이 값에는 **채널 게인 편향이 아직 실려 있다.** 계획 §3.1 대로 −2.9% 여지가 있고,
sensing §3 이 오늘 그 편향의 세 번째 증거를 냈다. §3.4 교정 후 재평가할 것 (조치 #37).

## 5. ⚠ 절대 전력은 런 간 ±2% 흔들린다 (신규 — 조치 #43)

같은 리그·같은 인자·16분 간격의 재실행이다.

| | cold → warm |
|---|---:|
| id1 단독 | **+1.63%** |
| id2 단독 | **+0.83%** |
| 짝 (총전력) | **−2.11%** |

**부호가 갈린다.** 단독은 올라가고 짝은 내려갔다. 이 대조 수준(16분 휴식, 최대 1500 rpm)의
열 효과가 런 간 흔들림에 묻힌다는 뜻이다.

> **절대 전력에서 4% 이하 차이는 n=1 로 판정하지 않는다.**

이것이 **비(ratio) 가 신뢰할 만한 이유**도 설명한다 — 같은 런 안에서 나오므로 런 수준
오프셋에 면역이고, 실제로 §3 의 전/후 비는 독립적인 두 열 대조에서 −2.55% / −2.61% 로
재현됐다. 이 저장소가 처음부터 비를 앞세운 관례가 여기서 수치로 정당화된다.

### 소급 적용

| 이전 주장 | 재평가 |
|---|---|
| id2 `base2`→`cold2` 총P **−5.4%** | 흔들림의 2.7배 — **아마 실재하나 확정 아님** |
| 짝 총P `basep`→`coldp` **+0.9%** | **흔들림 안. 변화 없음과 구별 불가** |
| 전/후 −2.6% (열) | **유효** — 비 지표이고 두 번 재현됨 |

## 6. 08-26 §6.4 — 절대 전력 −26% 는 여전히 열로 설명된다

오늘 `cold→warm` 이 절대 전력에서 ~0 이 나온 것을 "그럼 −26%도 열이 아니었나"로 읽으면 안 된다.

| 대조 | 열 강도 | 결과 |
|---|---|---|
| 오늘 `cold→warm` | 16분 휴식, 최대 1500 rpm — **약함** | ±2% (흔들림 안) |
| 08-26 `base2→post2` | **3000 rpm 90분 직후** — 강함 | −26.2% |
| `post2 → cold2` (하룻밤) | 완전 냉각 | **+28.2% 회복** |

**회복이 그 드롭이 열이었다는 증거다.** id2 는 텐션 변경을 안 거치므로 이 경로는 깨끗하다.
조치 #23 은 이로써 **전/후 비에 대해서는 종결**이고, 절대 전력에 대해서는 열려 있다.
