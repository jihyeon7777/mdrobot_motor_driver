## 0. ★★ 제일 먼저 — 타이어 3 바퀴 (2 분, 모터 무관)

**세션의 다른 어떤 것보다 먼저.** 모터를 안 쓰므로 열·순서를 오염시키지 않는다.

```
python3 test/wheel_circ_push.py --read          # ① 판독
   (타이어에 표식 → 접지점 기준 정확히 3 바퀴 굴러가게 민다 → 바닥 거리 줄자)
python3 test/wheel_circ_push.py --read          # ② 판독
python3 test/wheel_circ_push.py --dist <거리> --legs "a1:a2>b1:b2" --tag circ3rev
```

**나오는 것 (가정 없이):**
- `counts/바퀴회전 = Δcount ÷ 3`
- `하중 하 구름둘레 = 잰 거리 ÷ 3`

**닫히는 것:**

| | 지금 | 3 바퀴 뒤 |
|---|---|---|
| counts당 거리 | **0.7613 mm** (09-05 실측, 확정) | 그대로 — 교차검증만 |
| counts/바퀴회전 | 900 (틀림) · 실물은 **≈1031** 추정 | **확정** |
| 벨트 방향 | 22T:17T 인데 증속/감속 미상 | **확정** |
| counts/모터축 | 30 (근거 없음, 의심됨) | **확정** |
| `twin` `wheel_radius` | 0.004233 (틀림, 그대로 둠) | `0.0007613 × counts_per_rev / 2π` |

⚠ **표식은 타이어에, 기준은 접지점.** 3 바퀴를 세는 것이 이 측정의 전부다 —
한 바퀴만 하면 판독오차가 3 배로 실린다.

> 배경은 `docs/hardware_test_20260905.md` §6. 요지: 감속기 30:1 뒤에 **타이밍벨트단
> (모터측 22 T : 바퀴측 17 T)** 이 있는데 저장소의 어느 파일도 그것을 몰랐다.
> 250 mm 타이어에 맞는 1031 은 30:1(900) 도 30×17/22(696) 도 30×22/17(1165) 도
> 아니라서, **`30 counts/모터축` 이 틀렸을 가능성이 크다.**

## 2. ★ 미끄러짐 — 09-03 §4.2 가 철회한 것을 처음으로 잰다 (약 15 분)

09-05 §4.4 가 남긴 마지막 계통오차다. **F_eq 는 엔코더 거리를 `v` 로 쓴다** — 미끄러지면
실제 `v` 가 작고 **F_eq 는 더 크다.** 손밀기는 견인력 0 이라 이것을 못 본다.

**방법**: §0 의 줄자 구간을 그대로 쓴다. 시작선에 바퀴 접지점을 맞추고 `load_manual` 로
한 방향 구동, 완전히 세운 뒤 **정지 위치를 줄자로 잰다.** 정지 상태 판독이라 타이밍
오차가 없다.

```
python3 test/load_manual.py --rpm 600 --max-rpm 1500
```
- **600 rpm 한 레그** (저속 = 미끄러짐 최소) · **1500 rpm 한 레그**
- 각 레그 전후로 `--read` 판독 (다른 터미널) 또는 marks 의 `dpos` 를 쓴다
- 미끄러짐 = 1 − (줄자 거리) / (Δcount × 0.7613 mm)
- ⚠ §0 이 끝난 뒤에 할 것 — counts당 거리가 확정돼야 대면이 성립한다

**볼 것**: 저속에서 ≈0 이고 고속에서 커지면 견인 한계 몫이다. 둘 다 0 이면 F_eq 는
그대로 확정이고, §4.4 항목을 닫는다.

## 3. ⚠ 드리프트 — 구동 예측이 관측과 반대다 (약 10 분)

09-05 §6.5 가 낸 **검정 가능한 예측**:

| | 예상 | 근거 |
|---|---|---|
| 손밀기 | 왼쪽 **9.4 cm / 6 m** (관측됨) | 자유 바퀴 · 몸통 회전 1.79° |
| **구동 (같은 rpm)** | **오른쪽 16 cm / 6 m** | 좌우 둘레차 −0.41% 가 강제 조향 |

**그런데 조작자는 구동에서도 왼쪽으로 흘렀다고 보고했다 — 예측과 반대다.**

§2 의 구동 레그를 하는 김에 **바닥에 로봇 중심선을 표시하고 횡이탈을 재면** 끝난다.
방향과 크기 둘 다 필요하다.

- **오른쪽 16 cm** → 예측 적중. 좌우 둘레차가 구동 드리프트의 주인이다
- **왼쪽** → 다른 것이 덮고 있다. 1 순위 후보는 두 모터의 **반대 방향비**
  (id1 0.939 / id2 1.101) 가 만드는 방향 의존 미끄러짐 — §2 와 같은 자료로 본다

⚠ 손밀기 드리프트(왼쪽 9 cm)의 원인도 아직 셋이다: **바닥 경사 · 미는 습관 · 토 어긋남.**
바닥을 90° 돌려 같은 구간을 밀어 보면 경사가 갈린다 (경사면 방향이 따라 돌고, 토면 안 돈다).
